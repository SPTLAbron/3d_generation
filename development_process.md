Designed the trophy rendering.
I first created a procedural basketball-trophy generator. I was initially hardcoding the values for the base, body, ball, and support so that I could see if this was a viable approach. From various tests, I narrowed the entire makeup of the trophy to 10 variables, which could be independently controlled and used to create my dataset.
Created and inspected different trophy versions.
I then generated test versions of the trophies with a ±5 model-unit range for each parameter. When the changes were applied to the bases or the ball radius, the resulting trophies were still recognizable. However, when applied to any of the body parameters or the offset values, the resulting trophies were poorly shaped and disconnected. Through iterative testing, I landed on a specific range for each parameter where the extreme values still generated a coherent trophy. I then used an Claude to assist in automatically creating trophies when given a range of values to choose from.
Generated the dataset.
I then used the newly specified ranges and randomly sampled them to create 10,000 trophy meshes. I saved the parameter values used for each mesh and used them as ground-truth labels for analyzing the learned representations.
Voxelized and inspected the trophies.
I then normalized each trophy mesh and converted it into a 32×32×32 binary occupancy grid. During this process, I would periodically run a random check on the images to see if there were a large number of malformed trophies. When problems occurred I analyzed whether the problem was caused by the parameter ranges or the mesh-to-voxel conversion process, and then adjusted the corresponding stage. I also consulted Claude when debugging the conversion issues and to evaluate alternative approaches to mesh processing.
Created reproducible dataset splits.
I then divided the dataset into 80% training, 10% validation, and 10% testing subsets using a fixed random seed. I used the same splits for the autoencoder and variational autoencoder.
Researched possible reconstruction models.
I searched online for recent papers in 3d reconstruction and generative modeling. Initially, I was getting results related to 3d generation from multiple angles of the same 2d object, which did not match the purpose of my project. I then also employed ChatGPT and Claude to search specifically for methods that utilize 3D representations and eventually found SparseFlex: High-Resolution and Arbitrary-Topology 3D Shape Modeling. This paper was relevant to my planned workflow because it begins with 3D geometry, learns compressed representations of shape, and uses learned representations for geometry reconstruction and generation. 
Implemented my own 3D autoencoder.
Using these references, I created my own 3D autoencoder for the trophy dataset. The encoder reduces a 32x32x32 grid to a 32-dimensional latent vector, and the decoder reconstructs the voxel grid using 3D transposed convolutions. 
Iterated on the model and training configuration.
I then experimented with model and training choices, such as latent dimensions, channel sizes, and training duration. I compared experiments using validation performance and also visual inspection of the reconstructed trophies. When several consecutive iterations failed to make a meaningful impact, I used Claude to review the architecture and suggest adjustments that I missed. I then took these suggestions and made my own modifications based on past runs to select a final configuration.
Evaluated autoencoder reconstruction.
After selecting the final autoencoder configuration, I evaluated the reconstruction performance using binary cross-entropy, intersection over union, and Dice score. I also did a visual check on the trophies to make sure the strong results corresponded to accurate representations. 
Analyzed interpolation in the learned latent space.
I then encoded pairs of test trophies into their 32-dimensional latent representations and interpolated between them. I analyzed intermediate latent vectors to see if moving through the learned space gave smooth geometric transitions between the trophies. 
Measured how geometric properties were represented in latent space.
Since the original generator provided ground-truth values for all 10 geometric parameters, I wanted to see if those properties could be predicted from the learned autoencoder representations. I then trained linear property probes that map latent vectors back to the original geometric parameters and measured their performance using R2. This part of the project underscored what properties were represented strongly in the latent space and which properties were represented less strongly.
Tested semantic latent-space editing.
I then used the linear probe directions as candidate semantic directions for modifying each of the 10 geometric properties. After modifying a given latent vector along one of the 10 directions, I decoded it back into a trophy to see if the property I modified reflected in a meaningful change to the shape of the trophy. The results showed that only a few were successful.
Evaluated disentanglement of latent edits.
Building from the previous test, I then wanted to see if changing one property affected the dimensions of other parameters. I had some inclination that certain parts would impact each other, specifically the body parameters, but I wanted to see if perhaps the ball offset made a difference in the base location. After thorough testing, the results showed that some properties were independent and could be controlled meaningfully, while others relied upon a combination of properties.
Performed latent-space shape optimization.
I then used the learned property predictors as objectives for directly optimizing latent vectors. In one experiment, I specifically increased a trophy’s predicted lower-base radius while decreasing its predicted ball radius. I decoded the latent vector throughout the optimization process to verify that the targeted properties changed while the overall trophy remained coherent.
Implemented a 3D variational autoencoder.
I then extended the reconstruction approach into a variational autoencoder. I used the reparameterization step and trained the model with reconstruction loss and KL-divergence regularization so that it could reconstruct trophies and generate new shapes using latent sampling.
Compare AE and VAE performance.
I then evaluated both models of the test set, once again using binary cross-entropy, intersection over union, and Dice score metrics. When analyzing the results, the AE produced more accurate reconstructions, while the VAE sacrificed some accuracy in exchange for a latent space that could be sampled.
Evaluated VAE generation.
I then generated new trophies by sampling latent vectors. I initially ran at a 1.0 standard deviation, but the results were quite poor and resulted in disconnected geometry. Then sampling at 0.7 and then 0.5 resulted in much more coherent trophy structures.
Produced Final Visualization and Writeup.
Finally, I organized the results from phases, specifically reconstruction, generation, latent-space, editing, and optimization experiments, into the final repo visualizations and readme. I used ChatGPT to assist with visualization scripts, repository cleanup, and readme formatting. I then reviewed the final figures and reported results to ensure the writeup accurately reflected my experiments.
